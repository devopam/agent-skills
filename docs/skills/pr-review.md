# pr-review

Pre-submit and PR readiness review aimed at reducing rework before CI does.

**Use when:** before opening or updating a PR, or when reviewing someone
else's change set.

## Focus areas

Local hooks / lint / tests, intent & blast radius, tests for the change,
docs/changelog hygiene, CI readiness, diff-scoped security footguns.

Complements **python-code-review** (deep Python domains) rather than replacing it.
