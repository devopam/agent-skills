# python-code-review

Reviews Python code across **11 domains** with a scored report (0–10 per
domain, severity-ordered findings, overall verdict).

**Use when:** reviewing Python for quality, security, or production readiness;
before a commit/PR; or for a periodic health check.

## Domains (summary)

Standards compliance, code quality, security, dependency/supply-chain,
performance, concurrency & async, idioms & patterns, architecture,
observability, scalability & resilience, testing.
