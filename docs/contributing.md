# Contributing

Authoritative guide: [CONTRIBUTING.md](https://github.com/devopam/agent-skills/blob/main/CONTRIBUTING.md)
in the repository.

## Highlights

- Skills live at `skills/<name>/` per the [Agent Skills spec](https://agentskills.io/specification)
- **Research-before-authoring** for time-sensitive reference content
- Semver at the plugin/repo level (`.claude-plugin/plugin.json`)
- Validate with `claude plugin validate . --strict` when available

Please follow the [Code of Conduct](code-of-conduct.md).
