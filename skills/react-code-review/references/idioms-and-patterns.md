# Idioms & Patterns (React)

## Checks
1. Function components + hooks; avoid deprecated patterns.
2. Custom hooks for reusable stateful logic.
3. Controlled vs uncontrolled inputs chosen deliberately.
4. Server vs client components boundaries (Next app router) documented and correct.
5. Prefer composition over inheritance.

## Important
- Legacy lifecycle patterns in new code without need.
- Context used as a global variable dump.
