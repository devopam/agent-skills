# Report shape

1. Disclaimer (applicability aid; not legal advice / certification)
2. Context — confirmed packs, jurisdictions, role, data classes
3. Applicability table — in / out / uncertain + why
4. Obligation theme table — evidence present / partial / missing / unknown
5. Findings — Critical → Important → Minor → Not assessed
6. Remediation — What / Why / direction / **primary cite** / repo evidence
7. Source appendix — registry ids, URLs, snapshot ages
8. Optional baseline write path
