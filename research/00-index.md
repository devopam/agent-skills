# Research Index

Status tracker for `project-incubation`'s coverage baselines. Each row
corresponds to a file under `research/`, promoted into
`skills/project-incubation/references/` once `user-approved` (Phase 2). The
`research/` file stays in the repo afterward as a provenance record — see
`CONTRIBUTING.md` for the retention policy — with its key citations also
carried forward into the authored file's own Sources section.

Additional categories beyond this v1 scope are tracked in
`research/taxonomy-roadmap.md`, deferred until v1 is complete.
