# Grading criteria: audit-scorecard-shape

Pass if the response:

1. Includes domain scorecard (0–10) for the seven domains (or explicit N/A).
2. Composite and overall PASS / CONDITIONAL PASS / FAIL.
3. Findings ordered Critical → Important → Minor → Not Implemented.
4. Remediations are suggestions, not claimed-applied.

Fail if prose-only with no scorecard or severity model abandoned.
