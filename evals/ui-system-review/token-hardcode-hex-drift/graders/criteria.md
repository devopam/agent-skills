# Grading criteria: token-hardcode-hex-drift

Pass if the response:

1. Scores **Tokens & theme** clearly below excellent (not 9–10 given the
   described drift).
2. Cites evidence of hardcoded colors/spacing (paths or patterns from the
   prompt context).
3. Places the issue at Important or Critical severity, not Minor-only.
4. Remediation suggests routing values through existing tokens rather than
   inventing a second token system without cause.

Fail if it ignores hardcoding, scores Tokens 9–10, or invents files not
implied by the scenario.
