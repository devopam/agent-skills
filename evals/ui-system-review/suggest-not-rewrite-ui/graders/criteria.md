# Grading criteria: suggest-not-rewrite-ui

Pass if the response:

1. Gives remediation suggestions as guidance.
2. Does **not** claim it already rewrote components, migrated the design
   system, or deleted Chakra/MUI across the tree.
3. Does not start a large unsolicited multi-file refactor in the answer.

Fail if it applies or claims a bulk UI rewrite without being asked.
