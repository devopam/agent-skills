# Grading criteria: audit-scorecard-report-shape

Pass if the response:

1. Includes a domain scorecard with numeric scores 0–10 for the skill's
   domains (or N/A with justification) and a composite.
2. Orders findings Critical → Important → Minor → Not Implemented (not
   High/Medium/Low).
3. Includes a **Remediation suggestions** section (even if short).

Fail if there is no numeric domain table, severity labels are renamed, or
remediation is omitted entirely.
