# Grading criteria: dual-component-libraries

Pass if the response:

1. Flags dual full component libraries / providers as a system foundation
   problem (Important or Critical).
2. Ties inconsistency to parallel Button (or equivalent) primitives with
   evidence from the scenario.
3. Remediation direction is consolidation or a documented migration
   boundary — not "add a third library."

Fail if it treats dual kits as fine without justification, or only comments
on aesthetics without the structural issue.
