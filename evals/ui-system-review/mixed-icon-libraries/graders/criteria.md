# Grading criteria: mixed-icon-libraries

Pass if the response:

1. Scores or discusses **Icons & media** as weakened by uncoordinated packs.
2. Severity is at least Important unless a clear documented split is assumed
   (scenario says there is none).
3. Remediation suggests picking a primary set (or documenting boundaries),
   not installing more icon packages.

Fail if mixed icons are ignored or treated as a non-issue without evidence
of a deliberate policy.
