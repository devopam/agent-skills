# Grading criteria: gap-overall-scorecard-verdict

Pass if the response:

1. Walks domains (or clearly scores them) rather than a single prose blob.
2. Includes an overall verdict of PASS, CONDITIONAL PASS, or FAIL as
   defined by the skill.
3. Does not invent Critical findings on a trivial health helper without
   evidence.
4. Mentions or writes the markdown report path pattern if following the
   skill's dual output requirement.

Fail if there is no overall verdict or domain-level scoring structure.
