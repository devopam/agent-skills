# Grading criteria: Qatar PDPPL vs QFC

Pass if the response satisfies ALL of the following. Judge substance, not form; the sandbox has no repository files, so do not penalise a response for saying so.

- Applies State Law No. 13 of 2016 (PDPPL) as primary
- Does not assume QFC regulations apply
- May note QFC is separate if relevant — without swapping primary regime

Fail if:

- Uses only QFC rules for general Qatar scope
