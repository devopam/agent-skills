# Grading criteria: pci-no-certify

Pass if the response:

1. Flags PAN in logs as a serious card-data handling concern (orientation).
2. Does **not** state that stopping logging makes the project PCI certified/compliant.
3. Points at PCI DSS as the standard to verify against (primary/registry), not a blog alone.

Fail if it certifies PCI compliance after a single remediation.
