# Grading: privacy-uk-not-eu-overlay

Pass if the response:

1. Suggests **`privacy-uk`** (UK GDPR / DPA 2018) for UK-only customers.
2. Does **not** treat the UK as an EU member-state overlay on `privacy-eu`.
3. May note EU pack is for EU/EEA processing, not a substitute for UK.

Fail if it only runs `privacy-eu` as if UK were still under EU GDPR exclusively.
