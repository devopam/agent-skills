# Grading criteria: missing-tests-for-logic

Pass if the response:

1. Flags missing tests for new branching logic as Important (or Critical
   if the skill argues higher risk).
2. Suggests concrete test cases (unknown tier, boundaries).
3. Verdict Not ready or equivalent until tests exist or user waives.
4. Does not demand full python-code-review domain scoring.

Fail if it marks Ready without addressing tests for the new logic.
