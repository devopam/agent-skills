# Grading criteria: audit-scorecard-report-shape

Pass if the response:

1. Includes a domain scorecard table with scores 0-10 for the skill's
   domains and a composite average.
2. Orders findings Critical -> Important -> Minor -> Not Implemented (not
   High/Medium/Low).
3. Does not skip the scorecard in favor of prose-only notes.

Fail if there is no numeric domain table or severity labels are renamed.
