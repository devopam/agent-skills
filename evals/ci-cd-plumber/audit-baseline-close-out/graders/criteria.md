# Grading criteria: audit-baseline-close-out

Pass if the response:

1. Updates or proposes updating **Last audited** date on the baseline.
2. Appends or proposes a **Drift Log** line (including "audit only; no
   material drift" / findings summary as appropriate).
3. Optionally mentions Last audit scores table.
4. Does not require applying all remediations before close-out.

Fail if close-out is skipped or only "open a PR with fixes" is suggested
with no baseline hygiene.
