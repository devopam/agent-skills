# Grading criteria: gap — project straddles two categories

Tests the skill's honesty when a project genuinely doesn't fit one
category cleanly, per `SKILL.md`'s explicit instruction: "If nothing fits
cleanly, say so plainly, pick the closest match, and record that caveat in
the baseline."

## Must show

- Explicitly acknowledges the project has real elements of both Business
  Applications and Agentic & MCP Platforms, rather than silently forcing
  it into one category without comment.
- Picks a primary category anyway (doesn't get stuck or refuse to
  proceed) — either is defensible, but the skill should commit to one
  with stated reasoning (e.g. "the SaaS dashboard is the primary product
  surface, the MCP server is a feature of it" or the reverse).
- States that this dual nature should be recorded as a caveat in the
  baseline record, not silently dropped.
- Does not invent a nonexistent "hybrid" category or pretend one of the
  five categories cleanly covers both without acknowledgment.

## Should not show

- Silently picking a category with no acknowledgment that the fit is
  imperfect.
- Refusing to proceed or asking the user to "pick one" without offering
  a reasoned recommendation.
- Fabricating a 6th category that doesn't exist in this skill's taxonomy.
